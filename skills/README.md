# Canonical Neyvro skills

This directory is the source of truth for portable `SKILL.md` files. These contract-phase definitions specify activation, safety modes, inputs, outputs, and backend boundaries. Substantive playbooks are added later and must preserve these contracts.

Use `neyvro-skills validate`, `neyvro-skills search <terms>`, and `neyvro-skills load <exact-name>`. Read metadata first; load one skill on demand instead of injecting this entire directory into every request.
